# 06 — Phase 5.1 visual overhaul and review boundary

**2026-10-27 NZDT. Overall art acceptance: PARTIAL. Human visual/gameplay/audio approval: PENDING.** The overhaul is implemented across the existing valley. Character anatomy, clothing, architecture and vegetation have materially changed, but the rigid character animation and procedural environment remain below a finished commercial character-art standard. Passing engineering tests does not approve beauty or establish Atelier Ryza parity.

## What changed

- Original Blender surfaces replace the caretaker and all three capsule NPCs: about 6.7-head proportions, shaped jaw/neck/limbs/hands/boots, hair, cloth layers, seams, belt and satchel. Mira has a sage robe/apron/braid/herb basket; Wren has ochre workwear, a straw hat, apron and trowel; Alder has a slate tunic, cap, beard, tool pouch and mallet. They share an original anatomical base, with distinct role geometry.
- Clover has an original shaped body/head/neck, beak, comb/wattle, wings, tail feathers, legs and toes. The existing Body, Egg and state-indicator parents and 15-second gameplay timer remain.
- The mill has a tapered plaster shell, relief fieldstone base, timber courses/pilasters, framed windows, plank door/hardware and layered roof shingles. The existing broken/repaired sail groups and rotating SailsPivot remain authoritative; lattice bars, hub/bolts and a barrel/crate/planter/rope work yard add architectural detail.
- Branching trunks/root flares and solid leaf geometry replace sphere crowns throughout the map. Three proportion/color variants share the original branch model. Petalled flowers and broadleaf foliage replace button flowers and gathering plants; faceted mineral rocks retain original node collision. Grass/path colors and local native Terrain blending remove the former white-speckled lawn/opaque pilot path edge. Heights and gameplay coordinates are unchanged.
- The cottage gains visible overlapping shingles, framing, sill/mullion/door detail, fieldstone footing, hanging herbs, shelves, pots and fitted crate/barrel visuals. Garden flowers/foliage still derive from the existing dormant/bloom groups. Stream-bank pebbles/plants supplement the existing scrolling water. A non-colliding outer tree line adds a background layer.
- Shared URP Lit materials use original 256px color/normal textures and distinct cloth/leather/metal responses. Cool fill, restrained stage warmth/bloom and corrected shadow bias retain dimensionality. No depth-of-field blur or new rendering package was added.
- Forest-teal interface panels and seven original 64px item silhouettes update the UI. Inventory icons follow stable item ids when rows move; recipe cards use the same icon family. Existing text, input, menu actions, sliders and layouts remain, with updated AI credits.

## Reproducible source and preservation

`tools/art/build_pilot.py` creates editable Blender/FBX source and a mesh JSON intermediate. `PilotArt.Bake` writes native Unity meshes/materials; `WorldArt` and the existing generators own scene construction. Unity writes every scene, prefab, mesh and meta file. The export has **164 rig/material groups and 53,040 triangles**; the native library also includes a 100-triangle rough-stone mesh. Seven sprite assets are generated by code. Fresh Blender runs reproduce the mesh JSON SHA256 (recorded in the final report); Blender/FBX metadata is not claimed byte-identical.

Existing evidence and intermediate candidates are retained. Reference-kit contents and official study images stay local/ignored. No third-party model/texture/font/audio, official theme WAV, package upgrade or paid service was introduced. See [actual-use disclosure](03-RULES-CREDITS.md).

Gameplay definitions, controller/camera code, save v1 migration/v2, recipes, quests, rewards and the original 36 WAVs are unchanged. The only non-QA runtime display change selects inventory sprites by item id; credits describe current AI assistance. All visual stage application continues through the existing ResonanceStage authority. No new state booleans or completion rewards were added.

## Limits and next review

- Characters use the existing rigid procedural pivots, with no skinned mesh, independent elbow/knee deformation, production facial rig or authored animation clips. Character/NPC fidelity is **PARTIAL**, despite a substantial silhouette/anatomy improvement.
- Vegetation is a modest reusable branch/leaf library, with angular solid leaves and sparse procedural distant terrain. Some new dressing is visual-only. Terrain/vegetation/composition still benefit from artist review.
- The interface retains much of the original uGUI layout and built-in font. Icons, palette and readability were improved; a complete custom typography/layout system was not authored.
- Scripted frame samples on this Radeon 780M are not continuous human gameplay benchmarks. GPU timings, draw calls, VRAM, 1% lows, every camera/path, real mouse feel/Alt-Tab, human listening and another PC are NOT VERIFIED.
- Normal process exits are recorded individually. Non-reproduction of the historical `0xC000041D` native teardown fault does not establish its root cause or prove a fix.

The next step is owner review of the actual comparison gallery and a real keyboard/mouse/audio playthrough. No Git push or itch.io submission is authorized or attempted by this phase.
