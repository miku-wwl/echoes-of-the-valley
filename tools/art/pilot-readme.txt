Echoes of the Valley — Phase 5.1 visual PILOT REVIEW

This is an incomplete visual overhaul for review, not an approved RC2 or jam submission.
Only the caretaker and windmill neighbourhood use the new art pipeline. The rest of
the valley still has prototype visuals. Human visual, gameplay and audio QA are pending.

Run EchoesOfTheValley.exe alongside its Data, MonoBleedingEdge and DLL files.
Windows x64 / Direct3D11 / Unity 6000.3.27f1. No installation or internet is needed
by game logic. An actual disconnected-network test has not been performed.

WASD/arrows: move; mouse: look; E: interact/advance dialogue; I: satchel.
1–3: craft at the workshop. Esc: close a panel or pause.
Ending: Enter/E/Esc continues exploring; M returns to the main menu.

Normal play uses the existing local save folder. This pilot preserves save version 2
and v1 migration; use a backup before experimental play. The automated smoke runs
use their own isolated folders. Music and Sound sliders are on title/pause screens.

Created by the developer of this entry (public creator name not yet confirmed).
AI assistance: Anthropic Claude Code (original game code, writing, procedural art
and synthesised audio); OpenAI Codex (Phase 5.1 original Blender mesh art, texture
and material code, integration, QA tooling and documentation), directed by developer.
No external model, texture, audio or font file was imported. Unity built-in resources
and shaders are used. No official Atelier Ryza content or official jam theme recording
is included. The official gallery was visual study only.

This character uses rigid procedural pivots, not a skinned humanoid rig.
Do not interpret automated test success as approval of its artistic quality.
